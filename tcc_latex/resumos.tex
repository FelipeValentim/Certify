\begin{resumo}
A gestão eficiente de eventos acadêmicos e corporativos apresenta desafios logísticos significativos, desde o controle rigoroso de inscrições até a emissão confiável de certificados. Este trabalho detalha o desenvolvimento do Certify, um sistema completo de credenciamento e gestão de eventos concebido para solucionar esses problemas sistêmicos. A plataforma adota uma arquitetura distribuída, estruturada através de uma API RESTful em .NET 6 fundamentada na \textit{Onion Architecture}, e um aplicativo móvel cross-platform desenvolvido em React Native. O controle de segurança é assegurado pelo uso de tokens JWT stateless. Como diferenciais operacionais, o sistema utiliza o padrão EAV (Entity-Attribute-Value) para permitir a criação de formulários dinâmicos de inscrição, além de incorporar uma funcionalidade nativa de auto-checkin presencial instantâneo por meio da leitura de QR Codes criptografados com hashes. O fluxo da aplicação culmina na automação do motor documental, que utiliza algoritmos em C\# para substituir identificadores fixos e dinâmicos em arquivos do Microsoft Word, convertendo-os em lote para PDF e distribuindo certificados em tempo real por e-mail. Os resultados indicam que o Certify mitiga os principais gargalos dos eventos modernos, eliminando o contato físico em bilheterias e o trabalho manual excessivo dos organizadores.

\textbf{Palavras-chave}: Gestão de Eventos; React Native; .NET 6; Onion Architecture; QR Code; Automação de Certificados.
\end{resumo}

\begin{resumo}[Abstract]
 \begin{otherlanguage*}{english}
Efficient management of academic and corporate events presents significant logistical challenges, ranging from the rigorous control of registrations to the reliable issuance of certificates. This work details the development of Certify, a complete accreditation and event management system designed to solve these systemic problems. The platform adopts a distributed architecture, structured through a RESTful API in .NET 6 based on Onion Architecture, and a cross-platform mobile application developed in React Native. Security control is ensured by the use of stateless JWT tokens. As operational differentials, the system uses the EAV (Entity-Attribute-Value) pattern to allow the creation of dynamic registration forms, in addition to incorporating a native function for instant physical self-check-in through the reading of QR Codes encrypted with hashes. The application flow culminates in the automation of the document engine, which uses C\# algorithms to replace fixed and dynamic identifiers in Microsoft Word files, converting them in batches to PDF and distributing certificates in real time via email. The results indicate that Certify mitigates the main bottlenecks of modern events, eliminating physical contact at box offices and the excessive manual labor of organizers.

\textbf{Keywords}: Event Management; React Native; .NET 6; Onion Architecture; QR Code; Certificate Automation.
 \end{otherlanguage*}
\end{resumo}
